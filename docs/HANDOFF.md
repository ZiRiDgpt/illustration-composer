# Сдача тестового задания

Решение — плагин Figma «Сборка — конструктор иллюстраций», версия 0.3.0, с локальным смысловым модулем для свободных метафор.

## Что передать

- `illustration-composer-v0.3.0.zip`: исходники, manifest, готовый dist, локальный модуль, инструкция, архитектура, тесты, три SVG и запись действий.
- [Репозиторий GitHub](https://github.com/ZiRiDgpt/illustration-composer). Изначально создан приватным; перед передачей ссылки нужен доступ проверяющего.
- [Рабочую копию Figma с примером](https://www.figma.com/design/5JCRrjhDFq0q4h5vC7o7TZ/?node-id=5001-2). Просмотр без входа проверен; права не менялись.
- [Сверку каждого обязательного пункта](REQUIREMENTS.md), [проверки](RUNTIME-CHECK.md), [демонстрацию](../demo/demo.mp4).

## Быстрый показ

1. Откройте рабочую копию в Figma Desktop.
2. Плагин уже импортирован в Development. На новой машине импортируйте manifest из архива.
3. Выберите фрейм «Сборка» на Cover и запустите плагин.
4. Для свободной темы выполните `npm.cmd ci`, `npm.cmd run semantic`, дождитесь готовности модели. Покажите «Начать новую главу в жизни». По объектам и быстрым темам плагин работает без модуля.
5. Покажите 40 вариантов, схемы, импорт palette-mint.json, перетаскивание, поворот, копию, слои и смену роли. Сохранённые примеры — в recipes.json.
6. Скачайте SVG и откройте обратно: группы остаются векторами.
