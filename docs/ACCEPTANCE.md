# Повторная приёмка

Работайте только в редактируемой копии. Уже выполненные проверки и границы покрытия перечислены в `RUNTIME-CHECK.md`.

1. Импортируйте `manifest.json` в Figma Desktop и запустите плагин Development.
2. Подключите библиотеку: 40 вариантов, по 10 в S/L и главном/фоновом состоянии. Проверьте книгу и растение в обеих детализациях.
3. Проверьте схемы «Сирень», «Персик», «Мята» по таблицам исходника.
4. Повторите три рецепта `examples/recipes.json`, сравните с SVG.
5. Выберите предмет, переместите, поверните, скопируйте и удалите копию. Проверьте порядок слоёв, смену главного/фонового состояния и Undo.
6. Переключите схемы, вернитесь к исходным цветам. Проверьте позиции, контур, белые детали и фоновую шкалу. Дополнительно загрузите палитру JSON.
7. Измените копию обычными инструментами Figma, обновите превью.
8. Экспортируйте SVG и импортируйте обратно. Проверьте векторы, группы, маски и имена. Запустите `python scripts/verify-examples.py` для сохранённых примеров.
9. Перезапустите плагин: каталог и параметры выбранной сцены восстанавливаются.
10. В отдельной временной копии удалите исходник зарегистрированного предмета: ожидается понятная ошибка. Восстановите через Undo.

Для регрессии: `npm.cmd run check`, `npm.cmd test`, `npm.cmd run build`. Для запуска готовой сборки Node и npm не нужны.
