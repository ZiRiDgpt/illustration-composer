22–23 ноября 2026 года. Figma Desktop, установленный каталог `app-126.11.11`.

## Подтверждено в настоящем приложении

- Импорт manifest, запуск Runtime/UI, обмен сообщениями через вложенные sandbox iframe.
- Подключение всех 40 вариантов: 10 предметов × S/L × главный/фоновый. Первый проход находил 32; после исследования структуры добавлен профиль безымянных групп. Повторное подключение подтвердило 40.
- Извлечение «Сирени», «Персика», «Мяты». Первоначальное сопоставление по светлоте давало неверные контуры; заменено соответствием ячеек исходной таблицы. В реальном превью проверены чёрные контуры, белые и цветные детали.
- L «Учёба без отвлечений», 1200×630, «Сирень»: книга, лампа, ручка, два фоновых предмета.
- S «Финансовая грамотность», 1080×1080, «Персик»: кошелёк, монета, папка, два фоновых предмета.
- По списку «Телефон, наушники, пазл», L, 1080×1440, «Мята»: три главных предмета, без фоновых, место под заголовок.
- Выбор пазла через слои, создание копии (3 → 4), поворот на 15°, сдвиг на 10 пикселей, удаление копии (4 → 3).
- Повторный запуск: восстановление каталога, выбранной композиции и её параметров. Все форматы превью вписываются в окно целиком.
- Скачивание трёх SVG. Все три открыты обратно через Place image в рабочей копии. Исправление кириллических имён дополнительно проверено повторным импортом третьего SVG; предметы выбираются отдельными группами. Пробные импорты убраны, три рабочих композиции сохранены.

## Артефакты

- `examples/*.svg` — экспорт настоящих фреймов Figma. После экспорта применено то же исправление UTF-8 сущностей имён, которое теперь встроено в плагин; координаты и paths не менялись.
- `examples/recipes.json` — параметры воспроизведения.
- `docs/example-verification.json` — проверка XML, размеров, цветов, векторов и отсутствия изображений.
- `demo/demo.mp4` — 92-секундный монтаж реальной записи действий в Figma, без звука: свободная метафора, предметный сценарий, схема, правки и экспорт. Использован Windows Graphics Capture через ffmpeg, только окно Figma; пользователь явно разрешил этот способ записи. Убраны паузы, часть материала ускорена.
- `demo/*-figma.png` — скриншоты реальной проверки.

## Автоматические проверки и границы покрытия

`npm.cmd run check`, `npm.cmd test`, `npm.cmd run build` выполняются успешно; 21 тест. Адаптерные тесты используют заменитель Figma API. Фактическая структура исходной библиотеки закреплена fixture.

Автоматически проверены все раскладки/форматы, общий масштаб, преобразования повёрнутых групп, составные книги, ручное переопределение каталога, редактирование, смена роли, порядок слоёв, сохранение каталога, повторная перекраска, gradient stops и откат при ошибке. Намеренное удаление источника и нештатные paint-типы проверялись на тестовом адаптере. Не заявляется исчерпывающая ручная проверка всех 40 рисунков во всех схемах.

- Новая свободная метафора «Начать новую главу в жизни» в настоящем Figma выбрала книгу и ручку. «Дать идее прорасти» — ручку, растение и книгу. Это запрос к настоящей локальной модели, а не к словарю восьми тем. Отдельный живой тест шести формулировок сохранён в `semantic-verification.json`.

- Книга перемещена на передний, затем на задний план; порядок подтверждён списком слоёв, затем восстановлен передний план.

- В Share личной копии обнаружено существующее право Anyone can view. Права не менялись. В отдельном встроенном браузере без входа в аккаунт открылась именно итоговая композиция `node-id=5001-2` и предложение Sign up — гостевой просмотр подтверждён.
