# Свободная тема и локальная модель

Режим «Свободная тема» использует `Xenova/paraphrase-multilingual-MiniLM-L12-v2` через Transformers.js 3.8.1, CPU, quantized ONNX. Модель получает только текст запроса. SVG, имена файлов и содержимое Figma в неё не передаются.

## Запуск

Нужен Node.js 20+. В каталоге проекта выполните:

```powershell
npm.cmd ci
npm.cmd run semantic
```

Дождитесь «Смысловой подбор готов». Затем используйте плагин. При первом запуске скачиваются около 135 МБ файлов модели с Hugging Face в `.cache/semantic/`. После загрузки обработка запросов локальная и не требует API-ключа или платного аккаунта. Модель и node_modules не входят в Git и архив. Сервер слушает только 127.0.0.1:4174; Figma обращается к нему через localhost. Для остановки — Ctrl+C в терминале модуля.

Без модуля доступны «Быстрые темы» и режим «По объектам», библиотека, правки, палитры и экспорт. Ошибка соединения выводится явно, автоматической подмены смыслового результата нет.

## Как выбираются предметы

Для каждого из десяти предметов описаны четыре значения/ассоциации. Модель кодирует эти описания и свободный запрос в нормализованные векторы. Для каждого предмета берётся максимальная cosine similarity его ассоциаций с запросом. До трёх достаточно близких предметов передаются в проверяемый план сборки. Слабые дополнительные кандидаты не добавляются только ради количества. При слишком слабой связи выводится предложение уточнить запрос.

Смысловой поиск не является генеративной LLM. Он может ошибаться и ограничен образами имеющейся библиотеки. Пользователь видит объяснение выбора и может заменить или добавить предметы вручную.

## Проверка

При запущенном сервере: `npm.cmd run test:semantic`. Используется настоящая модель, без заглушки. Проверяются шесть новых формулировок, принадлежность результата библиотеке, некорректные входные данные и чужой Origin. Результат — `semantic-verification.json`. Сборка по свободной метафоре отдельно проверена в настоящем Figma Runtime.
