# Демонстрация

`demo.mp4` — запись реальных действий в Figma Desktop, 92 секунды, без звука. Захвачено только окно Figma. Показаны свободная метафора «Дать идее прорасти», смена палитры, режим по предметам, поворот, копирование/удаление, исправленное перетаскивание и скачивание SVG. Убраны длинные паузы; часть записи ускорена в 1,8 раза. Вставки сделаны из записи того же приложения, без имитации действий.

`poster.png` — кадр новой записи. Три PNG с именами примеров показывают исходные проверенные композиции версии 0.2.0; сами SVG находятся в `../examples/`. Для самостоятельного показа используйте `../docs/HANDOFF.md`.

`python scripts/make-demo.py` создаёт отдельный необязательный обзор `overview.mp4` из PNG и не заменяет запись действий. Для этого вспомогательного скрипта нужны Pillow и ffmpeg; плагин от них не зависит.
